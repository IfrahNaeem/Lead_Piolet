Building the login page for our web development assignment required more thought than expected once we added proper form validation. Initially we only checked that the email and password fields were not empty, but the assignment also required checking for a valid email format and a minimum password length before allowing submission. I chose to do this validation on the client side using JavaScript for immediate feedback, but I also added the same checks on the server side, since relying only on client side validation would let someone bypass the checks entirely by sending a request directly. This assignment helped me understand why client side and server side validation are both necessary rather than one replacing the other.
