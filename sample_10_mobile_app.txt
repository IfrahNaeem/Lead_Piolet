For our mobile application development assignment, we had to choose between building a native Android app or a cross platform app using a framework, and I ended up going with a cross platform approach given the time constraints of the semester. The main tradeoff I noticed while working on this was that cross platform frameworks made it faster to get a basic working version running on both Android and iOS, but certain platform specific features, like customizing notification behavior, required writing separate native code anyway. This made me realize that cross platform development is not really an all or nothing choice, since most real apps end up mixing shared code with some platform specific pieces where needed. Documenting this tradeoff in our report ended up being just as useful as the actual coding part of the assignment.
